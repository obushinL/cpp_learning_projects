# Parallel Accumulate Example

Небольшая демонстрация того, как распараллелить операцию `std::accumulate` с помощью `std::thread`.

## Описание

Вектор разбивается на блоки, каждый блок обрабатывается в своём потоке, затем результаты складываются.

## Файлы

- `parallel_accumulate.cpp` — исходный код с реализацией шаблона `parallel_accumulate`.
